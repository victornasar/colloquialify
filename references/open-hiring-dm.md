# Open-hiring DMs

Use when the recipient publicly said hiring is open, applications are open, or
“DM me if you know anyone / if you’re interested.”

This is **not** cold-email problem discovery. Do not use the skeptic/trade
intrigue-question shape.

## Shape

1. Name opener (`Hey Name.`). Audience-tuned: salaam + short dua for Muslim
   recipients; plain `Hey` for secular.
2. Saw the post + what they’re hiring for (one concrete line).
3. Who I am + direct want-in stance.
4. Offer the resume (or portfolio) as the only ask.

Blank lines between beats so it reads on mobile. No em dashes.

## Example (shape only — do not parrot)

```
Hey Akshaya.

Saw your post about hiring engineers for Grok Bot. I'm a full-stack engineer and I want in.

Want me to send my resume?
```

## Cut

- Recruiter jargon the writer wouldn’t say: “req,” “loop,” “pipeline,” “top of funnel”
- Mission / passion fluff
- Soft chat asks (“happy to hop on a call,” “would love to connect”)
- Restating a rejection story unless the user asks to include it
- Emoji unless the channel and profile clearly call for playful secular tone

## If they already rejected a related role

Keep the same spine. Add one plain rejection line before the want-in, then ask
who has the other openings in plain English (still no “req”).
