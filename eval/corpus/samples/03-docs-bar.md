People ask if we should ban AI-generated docs in the repo. I don't think a ban helps.

What helps is a house style that's picky about claims. No "seamless." No "revolutionize." If a sentence could sit in any product README by swapping the noun, cut it.

I write docs the same way I write tickets: say what changed, who it affects, and how to verify. If I need a metaphor, I usually don't.

The bar isn't "sounds human." The bar is "a teammate can act on this without asking me in Slack."
