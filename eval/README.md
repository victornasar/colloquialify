# Eval overview

Colloquialify ships a tiny A/B/C evaluation workflow so voice preservation can be
checked instead of assumed.

| Piece | Role |
|-|-|
| [SCORING.md](SCORING.md) | Rubric and output table |
| [corpus/](corpus/) | Synthetic author samples + AI-flavored inputs |

Suggested first run: build `voice.md` from `corpus/samples/`, rewrite
`corpus/inputs/01-ai-coding-assistants.md` as B and C, then fill the scoring table.
